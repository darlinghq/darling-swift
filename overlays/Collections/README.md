# swift-collections modules used by the Foundation overlay

`RopeModule` (BigString) and `InternalCollectionsUtilities` from
[apple/swift-collections](https://github.com/apple/swift-collections), tag 1.1.6, commit
`c11818f3cae0780656baa430b49e7f163f08dffd`: the `Sources/RopeModule` and `Sources/InternalCollectionsUtilities`
directories, only their `.swift` files (including the gyb-generated ones the project keeps in `autogenerated/`),
unmodified. AttributedString in the Foundation overlay stores its text in BigString. Both modules are compiled
without library evolution and linked into libswiftFoundation.dylib, which does not export their symbols.
